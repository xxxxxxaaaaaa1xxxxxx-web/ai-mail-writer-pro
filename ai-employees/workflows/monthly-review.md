# 月次レビューワークフロー

## 概要
毎月1日に実行される、CEOへの1ページレポート生成と必要承認事項の自動収集ワークフロー。CEOの月稼働時間を **5分以下** に抑える唯一の接点。

## タイムライン

```
月初1日
00:00 │ ミネルバ：前月全データ集計開始
02:00 │ ミネルバ：月次データ完成→ハデスへ送信
03:00 │ ハデス：月次戦略評価
       - KPI達成度評価
       - 各AI社員のパフォーマンス評価
       - 来月の戦略仮説立案
05:00 │ ハデス：CEOレポート生成
06:00 │ ハデス：CEO通知送信（Slack/メール）
       - 受信時刻：CEOの起床時刻に合わせて自動調整可
       - 添付：1ページPDF + 詳細データ別ページ
```

## CEOレポート生成ロジック

### 1ページに収めるための優先順位

ハデスが以下の優先順位で「1ページに収まる項目」を選定：

```
[必須] 月間売上総額
[必須] 前月比成長率
[必須] 月次目標達成率
[必須] CEO承認待ち事項（あれば最大3つ）
[推奨] ヒット商品TOP3
[推奨] 月の学び1〜3行
[任意] 来月のフォーカス3項目
[任意] 異常事象ハイライト
```

総文字数 **600字以内**、グラフ最大2点。

### CEOアクション要請の判定

ハデスは以下のいずれか発生時のみCEO承認を要請：

| 事項 | 例 |
|---|---|
| 新プラットフォーム参入 | 「Patreonへの参入を提案。月次$200の固定費発生」 |
| 大型ジャンル参入 | 「アダルト系参入を提案。法務確認要」 |
| 月次予算の超過 | 「画像生成APIコストが想定の200%、上限引き上げ提案」 |
| 法務リスク | 「DMCA通知1件受領、対応方針承認要」 |
| 重大なBAN | 「Substackアカウント警告、戦略変更要」 |

**承認待ちが0件の月は、CEOは「了解」のスタンプ1つだけで完了。**

## CEO応答フォーマット

CEOは以下のいずれかを返すだけ：

| 応答 | 意味 | ハデスのアクション |
|---|---|---|
| 👍 / 「OK」 | 全て承認 | 全項目進行 |
| 🚫 + 項目番号 | 該当承認却下 | 該当項目のみ却下、代替案策定 |
| ❓ + 質問 | 詳細説明要 | 詳細レポート作成→再送 |

**5分以内にCEOアクション完了が標準。**

## 月次評価の自動化

### 各AI社員のKPI評価

ミネルバが各AIのKPI達成度を採点：

| AI社員 | 主要KPI | 評価方法 |
|---|---|---|
| ハデス | 月次売上達成率 | 100%以上=A, 80-99%=B, ...| 
| アテナ | 提案ジャンル成功率 | 70%以上=A |
| アポロン | 売上期待値の的中度 | 予測±20%以内=A |
| ムサシ | 納期遵守率 / オリジナリティ | 100% / 0%=A |
| ヘルメス | Grammarly品質 | 95+=A |
| カルメン | CTR/CVR | 各PF基準値+20%=A |
| ヤヌス | 出品成功率 | 100%=A |
| クロノス | 価格テスト勝率 | 60%以上=A |
| イリス | SNS送客数 / 月 | 3,000+=A |
| ミネルバ | レポート精度 | 異常検知誤報10%以下=A |
| アマテラス | CSAT / 応答時間 | 4.5+ / 4h以内=A |

### 自動再学習トリガー

3ヶ月連続でB評価以下のAI社員 → ハデスがプロンプトの自動改善を実行：

1. 失敗パターン分析
2. プロンプトの該当セクション書き換え
3. 1週間A/Bテスト
4. 改善版を本番投入

## 期待KPI（月次）

| 指標 | 目標 |
|---|---|
| CEO月次対応時間 | 5分以下 |
| レポート品質 | 1ページで全て理解可能 |
| 承認事項の的中率 | 90%以上（CEO却下率10%以下） |
| 月次総括精度 | データ誤差1%以内 |
