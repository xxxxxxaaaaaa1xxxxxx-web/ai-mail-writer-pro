# 日次制作ワークフロー（完全自動）

## 概要
平日（月-金）に毎日3本の新商品を全プラットフォームに自動投入する完全自動パイプライン。CEOの介入は一切不要。

## 詳細フロー

### Step 1: ムサシの原稿生成（06:00 - 10:00）

**入力**：アポロンの週次発注書（月曜04:00確定済み）から本日分3テーマを取得
**処理**：
1. 各テーマについて以下を実行：
   - キャッシュチェック（似た既存記事との重複検証）
   - Claude Opus 4.7で5,500-8,000字を生成
   - Originality.ai で重複チェック（85%以上ユニーク必須）
   - 禁止語リストフィルタ
2. 3本完了次第、ヘルメスのキューに投入

**所要時間**：約4時間（並列実行で短縮）
**失敗時**：自動リトライ3回 → 失敗時はハデスにアラート、当該テーマ翌日に持ち越し

### Step 2: ヘルメスの英訳（10:00 - 12:00）

**入力**：ムサシから日本語原稿
**処理**：
1. DeepL API で一次翻訳
2. Claude Sonnet 4.6 で文化的ローカライズ
3. ローマ字保持リスト（kaizen, ikigai等）に従って日本語概念を保持
4. Grammarly API で品質スコア95以上を確認
5. SEOキーワード5個を本文中に自然挿入

**所要時間**：約2時間
**失敗時**：Grammarlyスコア95未満 → Claude再生成、3回失敗で次工程引き継ぎ＋ハデス通知

### Step 3: カルメンの販売素材作成（12:00 - 14:00）

**入力**：ヘルメスから英語コンテンツ
**処理**：
1. プラットフォーム別タイトル生成（Gumroad/Medium/Substack 各最適化）
2. LPコピー（PASフォーミュラ準拠）作成
3. DALL·E 3 / Midjourney でサムネイル生成（各PF用アスペクト比）
4. プレビュー部分（15-20%）の切り出し
5. CTA・タグ・カテゴリ定義

**所要時間**：約2時間
**失敗時**：画像生成API失敗時はバックアップAPI（Stability AI）に自動切替

### Step 4: ヤヌスの自動出品（14:00 - 15:00）

**入力**：カルメンから販売素材パッケージ
**処理**：
1. **Gumroad**：API経由で出品（PDF添付、価格、サムネ、タグ設定）
2. **Medium**：API経由で記事公開（publication指定、Gumroad CTA挿入）
3. **Substack**：APIまたはPlaywrightで配信
4. **その他PF**：各APIまたはPlaywright自動化
5. 全URL収集→ミネルバ・イリス・アマテラスに通知

**所要時間**：約1時間（並列出品）
**失敗時**：PF個別失敗は他PFに影響させず、24時間以内にリトライ

### Step 5: イリスのSNS発信（15:00 - 22:00）

**入力**：ヤヌスから新商品URL + ミネルバから売れ筋既存商品リスト
**処理**：
1. 新商品ローンチ告知（即時×3PF＝X/Threads/LinkedIn）
2. 教育的Tip投稿（既存商品からの送客）
3. ストーリーテリング投稿
4. データ統計投稿
5. CTA明示型投稿
6. ターゲット時差に応じた配信

**所要時間**：午後〜夜（連続）
**失敗時**：API rate limit時は次の時間帯に自動振替

### Step 6: ミネルバの日次分析（23:00 - 23:30）

**入力**：全PFのrawデータ（API経由取得）
**処理**：
1. 売上集計（USD換算、円換算）
2. 商品別CVR算出
3. 異常検知（前日比 -50%/+200%等）
4. クロノス・アポロン・カルメン・ハデスに最適化レポート送信

**所要時間**：30分
**失敗時**：データ欠損時は確実なPF分のみで暫定レポート

### Step 7: クロノスの価格調整（23:30 - 24:00）

**入力**：ミネルバの分析レポート
**処理**：
1. ABテスト中の商品を統計的有意性でチェック
2. 値上げ/値下げルールに基づき価格変更
3. ヤヌスにAPI経由で価格更新を実行依頼
4. 顧客への通知メール（必要時）

**所要時間**：30分
**失敗時**：価格変更失敗時は元の価格を維持、ヤヌスとハデスに通知

## エラー時のフォールバック

| エラー種別 | 対応 |
|---|---|
| 1AI失敗（リトライ3回失敗） | ハデスに通知、当日該当作業のみスキップ |
| 2AI連鎖失敗 | ハデス → CEO通知 |
| 全工程停止（インフラ障害） | CEO即通知＋自動リカバリ実行 |
| 法的アラート | CEO即通知（深夜でも） |

## CEO関与点

**この日次ワークフローでCEOがやることはゼロ。**

例外：
- 法的アラート発生時のみ即時通知
- 月次レポート（月初1日06:00受信、5分で確認）
