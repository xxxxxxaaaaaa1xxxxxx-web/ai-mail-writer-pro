# 週次戦略ワークフロー

## 概要
毎週日曜22:00〜月曜04:00に実行される、翌週の制作・販売戦略を全自動で確定するワークフロー。

## タイムライン

```
日曜
21:00 │ ミネルバ：週次売上分析レポート作成
21:30 │ ミネルバ：カルメンへAB結果送信
22:00 │ ミネルバ：ハデスへ週次エグゼクティブレポート
22:30 │ ハデス：全社員から進捗データ収集
23:00 │ ハデス：翌週方針策定（KPI、優先テーマ、リソース配分）

月曜
00:00 │ アテナ：週次市場スキャン開始
03:30 │ アテナ：トレンドレポート完成→アポロンへ
04:00 │ アポロン：今週のジャンルTOP3選定→ムサシ・カルメンへ発注
```

## 詳細フロー

### Phase 1: 週次振り返り（日曜21:00 - 22:30）

**ミネルバの週次分析（21:00 - 22:00）**

集計内容：
- 週間総売上（USD/JPY）
- 商品別売上TOP10/WORST10
- PF別シェア
- 国別売上分布
- 新規顧客数 / リピート率
- ABテスト結果サマリ
- 各AIのKPI達成度

各AIへの分配：
| 受信AI | 内容 |
|---|---|
| クロノス | 価格テスト結果、CVR異常 |
| アポロン | ジャンル別売上ランキング、撤退候補 |
| カルメン | LP/サムネのABテスト勝者 |
| イリス | SNS別CVR、最適投稿時間 |
| アマテラス | 顧客満足度トレンド |
| ハデス | 全体エグゼクティブサマリ |

**ハデスの戦略策定（22:30 - 23:30）**

判断項目：
1. 翌週の重点ジャンル（アポロン提案を承認 or 修正）
2. 翌週の制作本数（標準15本/週、好調時20本まで増産可）
3. 価格戦略の方向性（強気 / 守り）
4. SNS投稿の重点（新商品 / 既存商品リバイバル）
5. CSの応答テンプレ更新

### Phase 2: 翌週準備（日曜23:00 - 月曜04:00）

**アテナの市場スキャン（月曜00:00 - 03:30）**

スキャン対象：
- Gumroad TOP100（Japanese関連）
- Medium トレンド記事（tag: japan / zen / minimalism）
- Substack リーダーボード
- Google Trends（過去7日）
- Reddit（r/JapaneseHistory, r/Buddhism, r/Minimalism）
- X/Twitter（Japanese morning routine, ikigai 等）

出力：
```json
{
  "trending_concepts": [...],
  "top_competitors": [...],
  "market_gaps": [...],
  "recommended_focus_for_apollo": [...]
}
```

**アポロンのジャンル選定（月曜04:00 - 04:30）**

スコアリング：
```
売上期待値 = (推定需要 × 客単価 × 完成可能性) / 競合密度
```

3テーマ確定後、ムサシ・カルメンに発注書送付。

## 月初の特別フロー（毎月1日）

```
00:00 │ ミネルバ：月次総括レポート作成（過去30日）
03:00 │ ハデス：月次戦略レビュー
   - KPI達成度評価
   - 戦略の継続/変更判断
   - 必要承認事項の洗い出し
06:00 │ ハデス：CEO月次レポート送信
       内容：
       - 1ページサマリ（売上・成長・課題・要承認）
       - グラフ：月次売上推移、商品TOP5
       - 来月のフォーカスエリア（3行）
       - CEO承認待ち事項（あれば最大3項目）
```
