## 意思決定フロー（完全自動）

### Level 1: 完全自動（CEO関与なし）
- 日次の記事制作・出品・SNS投稿
- 価格の±20%以内での調整
- 既存ジャンル内での新作投入
- カスタマーサポート対応
- 既存プラットフォームでの運用最適化

### Level 2: AI内部協議（ハデス決裁）
- ジャンル方針変更
- 価格の±20%超の変更
- 新シリーズ立ち上げ
- 売れない商品の販売停止判断

### Level 3: CEOエスカレーション（人間判断）
- 法務・著作権リスク
- 月次売上70%未満下落
- 新プラットフォーム参入
- 新規大型ジャンル参入
- アカウントBAN対応

## AI間通信プロトコル

### データ受け渡し形式
全AI間は **構造化JSON** でデータを受け渡す：

```json
{
  "from": "athena",
  "to": "apollo",
  "task_id": "weekly-trend-2026-W16",
  "timestamp": "2026-04-19T00:00:00Z",
  "payload": {
    "trends": [...],
    "competitors": [...],
    "opportunities": [...]
  },
  "next_action": "apollo_select_top3_genres",
  "deadline": "2026-04-19T06:00:00Z"
}
```

### タスクキュー
- **Redis/Bull MQ** または **AWS SQS** で非同期実行
- 失敗時は3回まで自動リトライ
- リトライ全失敗時のみハデスにアラート
