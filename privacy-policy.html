Privacy Policy

Last updated: March 31, 2026

1. Information We Process

AI Mail Writer Pro processes the following information:

  • Email content: Email body text displayed in Gmail is sent to the Anthropic API for AI reply generation, only when the user clicks the Generate AI Reply button.
  • Settings: Keigo level, work mode, and other settings are stored in browser local storage and are not sent externally.
  • API Key: The Anthropic API key entered by the user is stored in browser local storage and used only for API calls.

2. Purpose of Data Use

  • Generating email reply candidates via Anthropic Claude API
  • Generating email thread summaries
  • Managing usage limits for free plan

3. Third-Party Data Sharing

Email content is sent to the Anthropic API for AI reply generation. Please refer to Anthropic Privacy Policy for their data handling practices. We do not sell or provide user data to any other third parties.

4. Data Storage

  • Email content: Not stored on any server. Temporarily sent during API calls and discarded after processing.
  • Settings and API keys: Stored only in the browser local storage.
  • Generated replies: Exist only in browser memory and are discarded when the page is closed.

5. Security

All API communications are encrypted via HTTPS.

6. User Rights

Users can delete all stored data at any time by uninstalling the extension.

7. Contact

For privacy inquiries, please contact us via GitHub Issues.

8. Changes

This privacy policy may be updated as needed.
